# VEDA Technology – Level 1 Day 11
## Task 11: Basic Data Sorting & Filtering

### 📌 About the Project

This project was completed as part of the VEDA Technology Data Analytics Track – Level 1, Day 11.

The objective of this task was to practice basic data exploration using Microsoft Excel by sorting and filtering a retail sales dataset to answer simple business questions.

### 🎯 Objective

- Practice basic data sorting and filtering
- Explore retail sales data
- Apply multiple filters
- Extract useful business insights
- Preserve the original/raw dataset

### 🛠️ Tool Used

- Microsoft Excel

### 📊 Dataset

A retail sales dataset containing:

- Date
- Order ID
- Product
- Category
- Region
- City
- Units Sold
- Discount
- Sales
- Profit

The workbook contains 100 sample retail sales records.

### 🔎 Filters Applied

The following filtering conditions were applied:

1. Technology products in the North region
2. Sales greater than ₹500
3. Profit greater than ₹50
4. Office Supplies in the East region
5. Orders after 1 May 2026

Each filtered result was saved separately while keeping the raw data unchanged.

### 💡 Business Questions & Answers

**1. Which order has the highest sales?**

Answer: ORD-0015 (Laptop) – ₹5,850.00

**2. Which region has the highest total sales?**

Answer: West – ₹22,470.95

**3. Which category has the highest units sold?**

Answer: Technology – 218 units

**4. Which order has the lowest profit?**

Answer: ORD-0081 (File Folder) – ₹1.09

**5. How many orders have Sales > ₹500 and Profit > ₹50?**

Answer: 31 orders
